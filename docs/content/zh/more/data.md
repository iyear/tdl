# 数据

您的帐户信息将存储在 `~/.tdl` 目录中。

日志文件将存储在 `~/.tdl/log` 目录中。

每次运行都会写入独立的 `tdl-<进程ID>-<启动时间>-<唯一标识>.log` 文件，
因此同时运行的命令不会共用日志文件。日志中会记录命名空间。
可以按修改时间排序来查找最近运行的日志。

日志达到 10 MiB 时会轮转，每次运行最多保留三个压缩备份。
启动时，tdl 还会尝试清理最后修改时间超过七天且所属进程已退出的日志及备份。
如果进程仍在运行或无法检查其状态，则保留文件。进程 ID 被复用时，清理可能会延迟。
旧的 `latest.log` 及其备份不会被自动清理。
